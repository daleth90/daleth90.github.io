> [!note]
> Microsoft Bopomofo 是注音符號（ㄅㄆㄇㄈ）的英語音譯。

## Ctrl 起始

按住 Ctrl，然後一起按住對應符號按鍵。

- 逗號，：`Ctrl + ,`
- 句號。：`Ctrl + .`
- 頓號、：`Ctrl + '`
- 分號；：`Ctrl + ;`
- 冒號：：`Ctrl + Shift + ;`  (可看成 `Ctrl + :`)
- 驚嘆號！：`Ctrl + Shift + 1`  (可看成 `Ctrl + !`)
- 問號？：`Ctrl + Shift + /`  (可看成 `Ctrl + ?)
- 上大括號｛：`Ctrl + Shift + [`  (可看成 `Ctrl + {`)
- 下大括號｝：`Ctrl + Shift + ]`  (可看成 `Ctrl + }`)

## 反引號 \` 起始

先按下 \`（在上排數字 1 左邊），再按住相對應按鍵。

- 上括號（：\` -> `Shift + (`
- 下括號）：\` -> `Shift + )`

## 符號查詢視窗

符號查詢視窗 (打開/關閉)：`Ctrl + Alt + ,`

- 上單引號「：`符號查詢視窗` -> `=`
- 下單引號」：`符號查詢視窗` -> `\`
- 上雙引號『：`符號查詢視窗` -> `0`
- 下雙引號』：`符號查詢視窗` -> `-`
- 上書名號《：`符號查詢視窗` -> `u`
- 下書名號》：`符號查詢視窗` -> `i`
- 上書名號【：`符號查詢視窗` -> `o` 或 `Ctrl + [`
- 下書名號】：`符號查詢視窗` -> `p` 或 `Ctrl + ]`

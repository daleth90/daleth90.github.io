## 材料／份量

| 項次  | 材料                                                                 | 份量       |       |
| --- | ------------------------------------------------------------------ | -------- | ----- |
| 1.  | [佛蒙特咖哩 / 甜味](https://www.housefoods.com.tw/products/cd_84561.html) | 1/2盒     | 115g  |
| 2.  | 豬絞肉                                                                |          | 300g  |
| 3.  | 洋蔥                                                                 | 中型1又1/2顆 |       |
| 4.  | 紅蘿蔔                                                                | 中型3/4條   |       |
| 5.  | 紅椒                                                                 | 1顆       |       |
| 6.  | 毛豆(冷凍)                                                             |          | 200g  |
| 7.  | 沙拉油                                                                | 1大匙      |       |
| 8.  | 水                                                                  |          | 300ml |

## 作法

1. 洋蔥切碎、紅蘿蔔切5mm塊狀、紅椒切1cm塊狀。將毛豆解凍後，撥開並取出豆子備用。
2. 準備一個平底鍋預熱後，倒入沙拉油，加入豬絞肉、洋蔥、紅蘿蔔拌炒。
3. 待肉炒至上色後，加水沸騰，將浮末撈出，以中火燉煮約5分鐘。
4. 暫時關火，放入已撥成小塊的咖哩塊，以小火一邊攪拌一邊燉煮約5分鐘至醬汁成濃稠狀。
5. 關火，加入步驟1的毛豆、紅椒並攪拌均勻。
6. 白飯盛盤，淋上咖哩醬汁，即完成。
